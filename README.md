# Анализатор текста

Простая программа на Python, которая анализирует текст:
- считает количество слов, символов и предложений
- находит самое длинное слово
- вычисляет среднюю длину слова

## Технологии
- Python 3

## Как запустить
1. Установите Python
2. Запустите: `python text_analyzer.py`
