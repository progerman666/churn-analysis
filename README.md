# 📊 Анализ оттока клиентов (Customer Churn Analysis)

Предсказание оттока клиентов с помощью машинного обучения.

## 📌 Задача
По данным о клиентах предсказать, уйдёт ли клиент или останется.

## 🛠 Стек
Python, pandas, scikit-learn, XGBoost, matplotlib, seaborn

## 📊 Результаты
- Точность: 92% (XGBoost)
- AUC: 0.96
- Ключевые факторы: просрочки, количество обращений

## 🚀 Как запустить
### 1. Установить зависимости
pip install -r requirements.txt

### 2. Запустить скрипт
python churn_analysis.py
